# ☕ Brew & Focus

A cozy café-themed Pomodoro timer app with hand-drawn illustrations!

![Brew & Focus](public/screenshots/demo.gif)

## About
Brew & Focus lets you pick a drink, choose your session length, and focus — all inside a warm, illustrated café setting.

## Features
- 🍵 Choose your drink from a hand-drawn menu
- ⏱️ Three session lengths: small (25 min), medium (45 min), large (60 min)
- 🎨 Original hand-drawn illustrations made in Procreate
- 🔊 Typewriter sound effects and ambient café sounds
- 🐱 A little cat outside the café

## Built With
- HTML, CSS, JavaScript
- Vite
- Procreate (illustrations)

## Run Locally
```bash
npm install
npm run dev
```
